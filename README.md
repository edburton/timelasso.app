# timelasso.app

The public site for Timelasso, served by GitHub Pages. Plain static files; no build step.

The wordmark face is Bpmf Huninn (SIL Open Font License, see `OFL.txt`), subset to the letters the page uses.

The background loop is made from a Timelasso clip with `tools/sky.sh [-s] clip.MOV [x]` (`-s` steadies a take where the mount drifted); see the script for what it writes.
